# CiteVerify Extraction Module

This module is responsible for extracting information from uploaded academic PDFs.

## Features

- Extracts selectable text from PDFs
- Finds research claims
- Detects numeric citations such as [1]
- Detects author-year citations such as (Smith, 2024)
- Extracts references from a References section
- Maps citations to their corresponding references
